# Expense Tracker MCP Server (Supabase PostgreSQL Edition)

A production-grade, multi-tenant Model Context Protocol (MCP) server built with Python, [FastMCP](https://github.com/jlowin/fastmcp), and [Supabase PostgreSQL](https://supabase.com/). It exposes expense management tools and category resources to AI assistants and LLM agents.

---

## 🌟 Key Features

- **Supabase Cloud Database**: High-performance PostgreSQL backend managed via Supabase.
- **Multi-Tenant Isolation**: Filters transactions per user (`user_id`) extracted from HTTP headers (`x-user-id` or `x-consumer-username`).
- **Row Level Security (RLS)**: Compatible with PostgreSQL Row Level Security policies.
- **Strict Input Validation**: Validates dates (`YYYY-MM-DD`), non-negative amounts, 3-letter currency codes (ISO 4217), and sanitized `user_id` strings.
- **Multi-Currency Support**: Track expenses in any currency (`USD`, `EUR`, `INR`, `GBP`, etc.) with multi-currency summary aggregations.
- **Paginated Queries**: Supports `limit` and `offset` pagination to prevent LLM context window overflow.
- **Category Resources**: Exposes category taxonomies via MCP resources (`expense:///categories`).

## 📜 Supabase Database Setup

Before starting the server, run the following SQL script in your **Supabase Dashboard -> SQL Editor**:

```sql
CREATE TABLE IF NOT EXISTS public.expenses (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id TEXT NOT NULL,
    date DATE NOT NULL,
    amount NUMERIC(12, 2) NOT NULL CHECK (amount > 0),
    currency TEXT NOT NULL DEFAULT 'USD',
    category TEXT NOT NULL,
    subcategory TEXT DEFAULT '',
    note TEXT DEFAULT '',
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_expenses_user_date ON public.expenses (user_id, date DESC);

ALTER TABLE public.expenses ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow user access by user_id" 
ON public.expenses 
FOR ALL 
USING (true);
```

## 🚀 Getting Started

### Prerequisites
- Python >= 3.11
- [`uv`](https://github.com/astral-sh/uv) (recommended package manager)

### Installation & Environment Setup

1. **Clone & Install Dependencies**:
   ```bash
   git clone https://github.com/DecodeDebangi/expense-tracker-mcp-server.git
   cd expense-tracker-mcp-server
   uv sync
   ```

2. **Configure Credentials in `.env`**:
   Copy `.env.example` to `.env` and fill in your Supabase project URL and key:
   ```env
   SUPABASE_URL=https://your-project-ref.supabase.co
   SUPABASE_KEY=your-supabase-service-role-or-anon-key
   ```

### Running the MCP Server

```bash
# Run HTTP stream transport server on port 8000
uv run expense-tracker-mcp-server
```

## 🛠️ MCP Tools Reference

### 1. `add_expense`
Adds a single expense entry to Supabase.
- `date` *(str)*: Required date in `YYYY-MM-DD` format.
- `amount` *(float)*: Required cost amount (`> 0`).
- `category` *(str)*: Expense category (e.g. `food`, `transport`, `housing`).
- `subcategory` *(str, optional)*: Subcategory description.
- `note` *(str, optional)*: Notes or receipt details.
- `currency` *(str, optional)*: 3-letter ISO code (default: `"USD"`).

### 2. `list_expenses`
Lists expenses from Supabase within a date range with pagination.
- `start_date` *(str)*: `YYYY-MM-DD` start date.
- `end_date` *(str)*: `YYYY-MM-DD` end date.
- `category` *(str, optional)*: Filter by category.
- `limit` *(int, optional)*: Maximum rows to return (1-500, default: `100`).
- `offset` *(int, optional)*: Pagination offset (default: `0`).

### 3. `summarize`
Summarizes total spend grouped by category and currency in Supabase.
- `start_date` *(str)*: `YYYY-MM-DD` start date.
- `end_date` *(str)*: `YYYY-MM-DD` end date.
- `category` *(str, optional)*: Filter by specific category.
- `currency` *(str, optional)*: Filter by specific currency.

### 4. `update_expense`
Updates fields of an existing expense entry by its ID in Supabase.
- `expense_id` *(int)*: Unique integer ID of the expense entry.
- `date`, `amount`, `category`, `subcategory`, `note`, `currency`: Optional updated values.

### 5. `delete_expense`
Deletes an expense entry by ID from Supabase.
- `expense_id` *(int)*: Unique integer ID of the expense entry.

### 6. `bulk_add_expenses`
Inserts multiple expenses in a single atomic request to Supabase.
- `expenses` *(list[dict])*: Array of expense objects containing `date`, `amount`, `category`, and optional `subcategory`, `note`, `currency`.
